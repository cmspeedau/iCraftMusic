# iCraftMusic

A sleek, modern media manager for your personal collection of music, movies, TV shows, and podcasts—with syncing support for iPod and Rockbox devices.

## Vision

Keep your media library organized and make it easy to take your favorites anywhere. iCraftMusic brings discovery, library management, and portable-device syncing together in one thoughtful experience.

## Planned capabilities

- **One library:** Organize music, movies, TV shows, and podcasts.
- **Device syncing:** Transfer and manage media on iPod and Rockbox-compatible players.
- **Modern experience:** A clean, responsive interface designed to make large collections approachable.
- **Metadata and organization:** Keep titles, artwork, playlists, and library details tidy.

## Project status

This repository is the starting point for iCraftMusic. Product scope, supported platforms, and implementation details are still to be defined.
